#  Cricket Match Analytics Dashboard – Power BI

This project analyses cricket match data by extracting fixture and result information from a web-based GraphQL API and transforming it into an analytical dataset using Power Query. The Power BI dashboard provides insights into team performance, match outcomes, and opponent comparisons across multiple tournaments.

### Project Overview

The goal of this project was to build an end-to-end analytics pipeline that collects raw match data, transforms nested API responses, and visualizes key performance metrics through an interactive Power BI dashboard.

### Key Features

Analysis of match outcomes (win/loss trends)

Head-to-head team performance comparison

Runs and wickets comparison between teams

Identification of scoring patterns and performance trends

Interactive filters for exploring matches across tournaments and opponents

### Data Processing

Extracted data from multiple GraphQL APIs

Transformed nested JSON structures using Power Query (M)

Appended and cleaned multiple datasets to build a structured model

Created calculated columns and measures using DAX
